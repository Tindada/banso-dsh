# Banso 聊天 UI

`banso-dsh-ui` 是 DSH 浏览器插件，配合 `banso-dsh-web` 使用，向官方 renderer 的 `root` 插槽注册 Banso 页面。

## 集成要求

接口对齐 DSH `0.2.1-rc.2`；需要官方 `@deepseek-ai/dsh-api-session-controller` 和 `@deepseek-ai/dsh-client-ui-renderer` 客户端服务，由 Web bundle 配置依赖。宿主入口不提供独立业务服务，无需单独启动 UI。不要同时加载其他占用根页面的聊天 UI。

## 展示与限制

支持历史会话列表、新建、切换、重命名、连续追问、流式回答、停止和错误提示。桌面端显示侧栏，窄屏可展开列表；条目显示单行标题、相对时间和运行状态。不显示子 agent 会话、未选中的空会话、推理或注入上下文，不提供资料面板。

执行期间分别显示每次搜索、阅读的进行中、完成、失败或取消状态；可展开查看关键词、关注点、URL 和错误详情，并保留本轮先前的失败记录。仅展示整次调用，不区分下载与提取阶段。本轮完成、失败或停止后隐藏全部工具记录，服务端日志仍保留。

伴随工具调用的模型文字临时显示，当前步骤结束后消失；普通回答保留。

当前会话由 URL 的 `session` 参数记录，支持刷新及浏览器前进后退恢复；无此参数时首次发送创建会话。DSH 首次 token 认证会重定向至首页并移除查询参数，需先认证再打开会话地址。切换会话会清除输入草稿，不主动停止后台任务；较长历史可加载更早消息并保持阅读位置。

新会话默认用首条问题的前 30 个 Unicode 字符作为标题（合并空白，超长追加省略号），不额外调用模型。悬停或键盘聚焦时显示“…”菜单，触屏常驻，可选择“重命名”；Enter 保存，Escape 或“取消”放弃。保存失败保留输入和原名称，手动名称在追问、刷新和服务重启后保留。

模型回答支持 Markdown 和 GFM（包括表格、删除线、任务列表和自动链接），流式生成期间持续渲染；未闭合语法可能暂时改变排版。原始 HTML 被忽略；用户消息和工具详情保持纯文本。宽表格和代码块支持横向滚动。支持 KaTeX 数学公式：`$E=mc^2$` 为行内公式，独立公式用单独成行的 `$$` 包围，也兼容独占一行的 `$$公式$$`（即使紧接上一行说明）；正文中的双美元公式仍按行内处理。同时支持 `\(...\)` 行内公式和 `\[...\]` 独立公式（可跨行）；行内代码、围栏代码块及缩进代码块中的分隔符保持原样，普通括号不会被当作公式。样式和字体随前端打包，无需 CDN；长独立公式可横向滚动。流式输出中未闭合或无效的公式可能暂时显示原文或错误标记，不影响后续回答。美元金额建议转义为 `\$10`，避免多个 `$` 被当作公式分隔符。暂不提供代码语法高亮或 Mermaid。

运行配置和存储说明见 [Web bundle](https://github.com/Tindada/banso-dsh/blob/main/packages/web/README.md)。源码构建、消息投影和测试见 [开发文档](https://github.com/Tindada/banso-dsh/blob/main/docs/development.md)。
